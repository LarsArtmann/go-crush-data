01Pareto Breakdown

1% tier — 51% of the value: two confirmed correctness bugs

1. SessionFilter argument/placeholder mismatch (sessions.go): args() appends Day, ParentID, ByID while buildSessionsQuery emits conditions as ByID, Day, ParentID. Any filter combining ByID with Day or ParentID silently swaps the SQL parameters and returns zero rows. Reproduced: SessionFilter{ByID: "fixture-root", Day: fixtureDay()} returns ∅ instead of the session.

2. AgentGraph child ordering (agents.go): the documented contract is preorder “each subtree ordered by creation time”, but childSessions reverses a updated_at DESC query — which yields updated_at ASC, not created order. Reproduced: children created +1s/+2s but updated in reverse come back in the wrong order.
